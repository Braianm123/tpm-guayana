# TPM Guayana

Optimizador de Mantenimiento Preventivo (TPM) para talleres y pequeñas plantas de Ciudad Guayana, Venezuela.

- Registro de horas-máquina por equipo
- Cálculo de OEE por turno (Disponibilidad × Rendimiento × Calidad)
- Semáforo de alertas de mantenimiento preventivo (verde / amarillo / rojo)
- Historial de fallas y mantenimientos, MTBF por máquina
- PWA: se puede instalar en el teléfono y funciona sin conexión
- Los datos se guardan en el propio dispositivo (localStorage)

Proyecto de tesis de grado — Ingeniería Industrial, UNEG.

## Desarrollo local

```
npm install
npm run dev
```
